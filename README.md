# News Aggregator & Web Scraper

A Python-based web scraping application that collects and displays the latest news headlines and images from multiple news channels in real time.

## Features

- Fetches news from multiple sources
- Displays headlines with images
- User-selectable news channels
- Real-time content extraction
- Interactive command-line interface

## Technologies Used

- Python
- Requests
- BeautifulSoup
- IPython Display
